## Matplotlib

在 Matplotlib 里，像 `'b-o'`、`'r-s'` 这种写法，是把**颜色 + 线型 + 数据点形状**压缩到一个字符串里。

比如：

```python
plt.plot(x, y, 'b-o')
```

```text
'b-o'
 │││
 ││└─ o：圆点
 │└── -：实线
 └─── b：蓝色
```

常见参数还有：

|参数|意思|
|---|---|
|`b`|蓝色 blue|
|`r`|红色 red|
|`g`|绿色 green|
|`k`|黑色 black|
|`y`|黄色 yellow|
|`-`|实线|
|`--`|虚线|
|`:`|点线|
|`-.`|点划线|
|`o`|圆形点|
|`s`|方形点|
|`^`|上三角|
|`v`|下三角|
|`*`|星形|
|`x`|×形|

例如：

```python
plt.plot(x, y, 'g--^')
```

就是：**绿色 + 虚线 + 三角形数据点**。

所以你看到的 `'b-o'` 和 `'r-s'`，本质上就是 Matplotlib 为了方便，把三个参数简写在一起。
