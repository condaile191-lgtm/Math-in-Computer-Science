# 一次函数

y=ax + b 
图解要点：一次函数 `y=ax+b` 的图像是一条直线。调节 `a` 会改变直线的倾斜方向和陡峭程度；调节 `b` 会让整条直线上下平移，改变它与 y 轴的交点。

## ⭐⭐⭐陡峭程度
什么是陡峭程度？绝对值大小
|a|越大， 越陡
图解要点：同样是直线，`|a|` 越大，单位 `x` 变化带来的 `y` 变化越大，图像越陡；`a>0` 向右上升，`a<0` 向右下降。
|a|越小， 越缓

|a|越大，直线越陡，y 对 x 的变化越敏感
|a|越小，直线越缓，y 对 x 的变化越迟钝

## 二次项系数
抛物线 长相和脾气
决定抛物线核心特征：

开口方向
a>0 开口方向向上、a<0开口方向向下

开口大小（陡峭的程度）：
|a| 越大，开口越窄。
图解要点：当 `|a|` 变大时，抛物线在顶点附近更“尖”，离开顶点后 `y` 值增长更快，表示曲率或加速度更强。
|a| 越小，开口越宽。
图解要点：当 `|a|` 变小时，抛物线更“平”，同样的 `x` 变化只带来较小的 `y` 变化，曲率更弱。

在非线性关系中，a代表加速度和曲率。

## Matplotlib

在 Matplotlib 里，像 `'b-o'`、`'r-s'` 这种写法，是把**颜色 + 线型 + 数据点形状**压缩到一个字符串里。

比如：

```python
plt.plot(x, y, 'b-o')
```

```text
'b-o'
 │││
 ││└─ o：圆点
 │└── -：实线
 └─── b：蓝色
```

常见参数还有：

|参数|意思|
|---|---|
|`b`|蓝色 blue|
|`r`|红色 red|
|`g`|绿色 green|
|`k`|黑色 black|
|`y`|黄色 yellow|
|`-`|实线|
|`--`|虚线|
|`:`|点线|
|`-.`|点划线|
|`o`|圆形点|
|`s`|方形点|
|`^`|上三角|
|`v`|下三角|
|`*`|星形|
|`x`|×形|

例如：

```python
plt.plot(x, y, 'g--^')
```

就是：**绿色 + 虚线 + 三角形数据点**。

所以你看到的 `'b-o'` 和 `'r-s'`，本质上就是 Matplotlib 为了方便，把三个参数简写在一起。
