# 交集并集补集

交集：同时属于 A 和 B；并集：属于 A 或 B；补集：不属于指定集合。

集合运算可对应逻辑运算：交集≈AND，并集≈OR，补集≈NOT。

# python

Python 集合可用 `set` 表示，支持交集、并集、差集等操作。

示例：`A & B` 取交集，`A | B` 取并集，`A - B` 取差集。

## ⭐⭐⭐德摩根律

德摩根律：`not(A and B)=not A or not B`；`not(A or B)=not A and not B`。

例子：
not (x>0 and y >0) == not (x>0) or not (y>0)
也等于 x≤0 or y≤0

# ⭐⭐⭐逻辑的源头：判断真假

# 罗素悖论

罗素悖论：所有不包含自身的集合组成的集合，是否包含自身。
集合论经过公理化，仍然是现代数学的基础

罗素悖论说明朴素集合论中“任意定义集合”会导致自我指涉矛盾。

理发师悖论是罗素悖论的通俗版本。

理发师只给“所有不给自己理发的人” 理发

理发师给不给自己理发？
如果给，那么理发师就属于“给自己理发的人”，按照规则，他不能给这类人理发
如果不给，那么理发师属于“不给自己理发的人”，按照规则，他又给这类人理发

定义集合 S：S 由所有不属于自身的集合所组成。
S = { x | x ∉ x }

# ZF 公理集合论

增加限制：不能随便定义这种“全体集合”的集合，禁止这种自我指涉，堵住了悖论。
ZF: Zermelo; Fraenkel 策梅洛–弗兰克尔集合论
C=Axiom of Choice  **选择公理**
罗素悖论→发现朴素集合论有漏洞→建立严格的 ZF 公理体系→再加选择公理得到 ZFC

ZF 公理集合论通过限制集合构造规则，避免朴素集合论悖论。

ZFC = ZF 公理体系 + 选择公理。
